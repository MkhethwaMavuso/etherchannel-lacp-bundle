# etherchannel-lacp-bundle
Design, configuration, and verification of a multi-switch Layer 2 infrastructure deploying three distinct EtherChannel negotiation modes.

Quick Overview & Network Specs🟢 Architecture & Topology: Layer 2 Enterprise Switching Network featuring four Cisco Catalyst 2960-24TT switches (Switch2, Switch3, Switch4, and Switch5) configured in a physical square loop topology with dual-link trunk bundles between adjacent nodes.🔵 EtherChannel Protocols & Modes: Multi-protocol link aggregation comparison implementing:LACP (IEEE 802.3ad): Configured between Switch2 and Switch3 (Standard open protocol).PAgP (Cisco Proprietary): Configured between Switch5 and Switch4 (Auto/Desirable modes).Static Persistence (ON Mode): Hardcoded unconditional bundling configured between Switch3 and Switch4.🟣 Switching Topology & Loop Prevention: Native integration with Spanning Tree Protocol (STP / Rapid PVST+). STP treats each dual-physical-link EtherChannel bundle as a single logical port channel interface, preventing Layer 2 loops while providing immediate failover.🔴 Link Aggregation Group (LAG) Interoperability: Demonstrates proper negotiation parameters (duplex, speed, trunking encapsulation, allowed VLANs) across different negotiation methods (LACP, PAgP, and Static).🟡 Layer 2 Transit Infrastructure: Dual-gigabit/fast-ethernet physical links aggregated into logical Port-Channel interfaces (Po1, Po2, Po3) across all participating switch pairs.🟠 High-Availability & Bandwidth Multiplier: Provides full link redundancy and increased cumulative bandwidth (e.g., 200 Mbps / 2 Gbps full-duplex per channel) across interconnected access/distribution switches.💡 Key Technical Insights & What This Lab Demonstrates🔍 EtherChannel Protocol Mastery: Audits differences between LACP (channel-group X mode active/passive), PAgP (channel-group X mode desirable/auto), and Static/Manual (channel-group X mode on) operational behavior.⚡ Loop Prevention & STP Convergence: Demonstrates how Spanning Tree Protocol interacts with aggregated channels—blocking an entire Port-Channel logical path rather than individual physical links, preventing broadcast storms and MAC table instability.🛠️ Real-World Verification Skills: Accompanied by CLI commands and verification steps:show etherchannel summaryshow interfaces port-channelshow spanning-tree🛡️ Interface Consistency & Best Practices: Highlights the critical requirement for uniform interface speed, duplex, native
